# TaskFlow Dashboard

A responsive task management dashboard built with React and Vite. TaskFlow helps users organize tasks, monitor progress, and manage workspace activities through a clean, user-friendly interface.

## Features

- **Dashboard:** View task statistics and workspace information.
- **My Tasks:** Create, view, search, and manage tasks.
- **Calendar:** Organize and review scheduled activities.
- **Team Members:** View team member information.
- **Notes:** Manage workspace notes.
- **Reports:** Review task and project information.
- **Inbox:** Access workspace messages and notifications.
- **Responsive UI:** Adapt the interface for desktop, tablet, and mobile screens.
- **Sidebar Navigation:** Navigate between workspace sections.
- **Local Storage:** Retain supported application data in the browser.

## Installation and Setup

### Prerequisites

Install [Node.js](https://nodejs.org/) and npm before starting.

### 1. Clone the repository

````bash
git clone https://github.com/sakshichougule-09/taskflow-dashboard.git


### 2. Navigate to the project folder

```bash
cd taskflow-dashboard
````

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

### 5. Create a production build

```bash
npm run build
```

The production files will be generated in the `dist` directory.

## Mobile Support

TaskFlow uses responsive CSS to adapt the layout to different screen sizes. To test the mobile layout, open the application in Google Chrome and press `Ctrl + Shift + I`, followed by `Ctrl + Shift + M`.

## Data Storage

Application data stored in browser local storage is generally specific to that browser and device. It is not automatically synchronized between different users or devices.
